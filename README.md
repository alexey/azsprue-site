# AzSprue support site

Static pages for GitHub Pages: support (`index.md`), privacy policy and terms of use. `privacy.md` and `terms.md` are copies of the text below the line in `docs/PRIVACY_POLICY.md` and `docs/TERMS_OF_USE.md`; a unit test fails when they differ, so edit the documents in `docs/` and copy them here.

To publish: create a public repository (for example `azsprue-site`), put these files at its root, and turn on Settings → Pages → Deploy from branch `main`, folder `/`. The pages then live at `https://<github-user>.github.io/azsprue-site/`, `.../privacy/` and `.../terms/`.
